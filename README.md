# AI-Based FNAC Breast Cancer Detection

## Project Overview

This project explores breast cancer classification using deep learning on FNAC images.

## Technologies Used

* Python
* TensorFlow/Keras
* OpenCV
* Streamlit
* Grad-CAM

## Key Features

* Image-based classification
* Interactive Streamlit interface
* Grad-CAM visualization to help explain model predictions

## Disclaimer

This project is intended for educational and research purposes. It is not a substitute for professional medical diagnosis.
